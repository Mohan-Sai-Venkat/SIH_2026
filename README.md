# Automatic Block Planning System

## SIH 2026

An AI-based Automatic Block Planning System for coordinated railway maintenance.

## Problem

Railway maintenance activities for Engineering, Traction Distribution, and Signal & Telecommunication departments are currently planned independently. This can result in inefficient block utilization, scheduling conflicts, and increased asset downtime.

## Proposed Solution

Our system integrates maintenance, defect, corridor availability, and train timetable data to automatically generate optimized maintenance block plans.

## Key Features

* Integration of TMS, SMMS and TDMS maintenance data
* Corridor and block availability analysis
* Maintenance task prioritization using AI/ML
* Optimized block scheduling
* Coordination between multiple departments
* Weekly and monthly block planning
* Dashboard for monitoring maintenance and block schedules
